# 🕯️ ローソク足メーカー（Candle Maker）

FXの学習・検証用に、**ローソク足と水平ラインを自由に配置してチャートパターンを作成できるWebアプリ**です。

最大10本のローソク足を並べ、高値・安値・始値・終値を直接調整できます。\
レジスタンス／サポート、ラウンドナンバー、前日高値・安値、SMA20などを想定した水平ラインも追加できます。

作成したチャートはPNG画像として保存できます。

## 🌐 公開版

**https://pubunno.github.io/candle-maker/**

ブラウザで開くだけで利用できます。\
インストールは不要です。

## ✨ 主な機能

### ローソク足

-   最大10本まで作成
-   陽線・陰線を追加
-   ローソク足を選択して編集
-   ローソク足全体を上下にドラッグ
-   高値・始値・終値・安値を個別に調整
-   陽線／陰線の反転
-   ローソク足の左右並べ替え
-   個別削除
-   左から `1, 2, 3 ...` の足番号を表示
-   本数が変わってもローソク足の基本間隔を一定に維持

### 水平ライン

複数の水平ラインをチャート上に追加できます。

-   水平ラインをドラッグして上下移動
-   **実線／点線**を切り替え
-   ラインごとに自由なラベルを設定
-   個別削除
-   PNG保存時にもラインとラベルを表示

ラベルには、例えば次のような文字を設定できます。

-   ラウンドナンバー
-   レジスタンス
-   サポート
-   前日高値
-   前日安値
-   ネックライン
-   SMA20
-   その他、任意の文字

> `SMA20`
> などのラベルは、現時点では移動平均線を自動計算・描画する機能ではありません。\
> 水平ラインに意味を持たせるための自由ラベルとして使用します。

## 📱 PC・スマートフォン対応

画面サイズに応じてレイアウトが変化するレスポンシブデザインです。

PCではチャートを大きく表示しながら編集でき、スマートフォンではチャート領域を優先しつつ、操作ボタンや編集項目をコンパクトに配置します。

スマートフォンの横向き表示にも対応しています。

## 🚀 使い方

### 1. ローソク足を追加

**「＋ 陽線」** または **「＋ 陰線」** を押します。

ローソク足は最大10本まで追加できます。

### 2. ローソク足を編集

編集したいローソク足を選択します。

ローソク足本体を上下にドラッグすると、形を維持したまま全体を移動できます。

表示されるハンドル、または編集欄から以下を調整できます。

-   高値
-   始値
-   終値
-   安値

### 3. 水平ラインを追加

**「＋ ライン」** を押します。

追加した水平ラインは、チャート上で上下にドラッグできます。

ラインを選択すると、

-   ラベル
-   実線／点線

を編集できます。

### 4. 操作を戻す

**「↶ 戻す」** で直前の操作を取り消せます。

### 5. PNG保存

**「PNG保存」** を押すと、作成したチャートをPNG画像として保存できます。

PNGには、

-   ローソク足
-   足番号
-   水平ライン
-   水平ラインのラベル

が含まれます。

## 💡 想定用途

FXのチャート学習・検証を主な用途として想定しています。

例えば、

-   ローソク足パターンの再現
-   プライスアクションの学習
-   エントリー判断用の問題作成
-   レジサポとローソク足の位置関係の検証
-   「何本目で何が起きたか」の整理
-   トレード手法の教材画像作成
-   SNSやブログなどでのチャートパターン共有
-   ChatGPTなどのAIにチャートパターンを見せて分析

といった用途に利用できます。

-   Google Chrome
-   Microsoft Edge
-   スマートフォンのモダンブラウザ
