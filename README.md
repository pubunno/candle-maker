# 🕯️ ローソク足メーカー（Candle Maker）

FXの学習・検証用に、ローソク足の組み合わせを自由に作成できるシンプルなWebアプリです。

最大10本のローソク足を並べ、各ローソクの高値・安値・始値・終値を直接操作して、任意のローソク足パターンを作成できます。

作成したパターンはPNG画像として保存できるため、トレード検証、教材作成、チャートパターンの共有などに利用できます。

## 主な機能

-   最大10本のローソク足を作成
-   陽線・陰線を個別に追加
-   ローソク足の間隔を本数にかかわらず一定に表示
-   ローソク足を選択して編集
-   ローソク足全体を上下に移動
-   高値・始値・終値・安値を個別に調整
-   左から `1, 2, 3 ...` の足番号を表示
-   操作を1つ前に戻す
-   ローソク足を全削除
-   作成したパターンをPNG画像として保存
-   外部ライブラリ不要
-   インストール不要
-   PCのローカル環境でも動作

## 起動方法

`candle-maker-fixed-v4.html`
をPCに保存し、ChromeやEdgeなどのWebブラウザで開いてください。

特別なインストールやWebサーバーは必要ありません。

Windowsの場合は、HTMLファイルをダブルクリックするだけで起動できます。

## 基本的な使い方

### 1. ローソク足を追加する

画面上部の **「＋ 陽線」** または **「＋ 陰線」** をクリックします。

ローソク足は最大10本まで追加できます。

### 2. ローソク足を選択する

編集したいローソク足をクリックします。

選択中のローソク足には編集用のハンドルが表示されます。

### 3. ローソク足を編集する

ローソク足本体を上下にドラッグすると、形を維持したままローソク足全体を移動できます。

各ハンドルをドラッグすると、高値・始値・終値・安値を個別に変更できます。

これにより、長い上ヒゲ、長い下ヒゲ、大陽線、大陰線、十字線に近い形など、さまざまなローソク足を自由に作成できます。

### 4. 足番号

ローソク足には左から順番に、

`1  2  3  4  5 ...`

と番号が表示されます。

検証時に「3本目の下ヒゲ」「5本目で反転」など、特定のローソク足を指定しやすくするための番号です。

### 5. 操作を戻す

**「↶ 戻す」** をクリックすると、直前の操作を取り消せます。

### 6. 全削除

**「全削除」** をクリックすると、すべてのローソク足を削除します。

### 7. PNG保存

**「PNG保存」**
をクリックすると、現在作成しているローソク足パターンをPNG画像として保存できます。

足番号も画像に含まれます。

## 想定用途

このツールは特にFXのチャート学習・検証を想定しています。

例えば、

-   ローソク足の並び方を再現する
-   エントリー判断用の問題画像を作る
-   プライスアクションを比較する
-   「何本目で何が起きたか」を整理する
-   トレード手法の教材画像を作る
-   ChatGPTなどにローソク足パターンを見せて分析する

といった用途に使えます。

## 動作環境

HTML / CSS / JavaScriptのみで動作します。

外部ライブラリやインターネット接続は必要ありません。

主に以下のブラウザを想定しています。

-   Google Chrome
-   Microsoft Edge

## ファイル構成

``` text
candle-maker-fixed-v4.html
README.md
```

アプリ本体はHTMLファイル1つだけです。

## 現在の仕様

ローソク足は最大10本です。

少ない本数でも多い本数でも、ローソク足同士の基本的な間隔は変わらない設計になっています。

各ローソク足には左から連番が表示されます。
